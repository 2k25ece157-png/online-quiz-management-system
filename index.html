DATA STRUCTURES

Why these structures?

We selected each structure according to the problem it solves.

🔗 Singly Linked List

Used for Question Management

Each question is stored in a node and points to the next question. This supports dynamic insertion, deletion and traversal.

Q1 → Q2 → Q3 → NULL
  • Dynamic storage
  • Insert / delete / traverse
  • No fixed question count

🚶 Queue

Used for Student Attempts

Students are handled in order. The first student entering the queue is processed first.

FRONT → Student A → Student B → Student C → REAR
  • FIFO — First In, First Out
  • Enqueue / dequeue
  • Ordered processing
