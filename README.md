# Online Quiz Management System
College capstone website demonstrating C, Singly Linked List and Queue.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public website URL.

Note: The website interface/demo runs in HTML/CSS/JavaScript. It visually demonstrates the C data-structure capstone; it does not falsely claim the web interface itself is written in C.
